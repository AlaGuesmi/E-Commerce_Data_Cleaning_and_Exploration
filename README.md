# E-Commerce_Data_Cleaning_and_Manipulation
This project simulates a small e-commerce dataset with a mix of numerical, categorical, and textual data. Using pandas and NumPy, the project focuses on preprocessing and exploring the data to prepare it for further analysis or modeling.

🧰 **Tools Used**

Pandas for data manipulation and analysis

NumPy for handling numerical operations and missing data

📋 **Dataset Overview**

The dataset contains 100 records with 10 features, including:

Customer demographics (Age, Gender, Country)

Purchase behavior (Product Category, Purchase Amount, Rating, Review)

Transaction details (Date, Loyalty Membership)

🔍 **Key Steps Performed**
Data Loading & Initial Exploration

Handling Missing Values in age and rating

Encoding Categorical Variables for model readiness

Feature Engineering such as extracting month from purchase date

Data Transformation for consistency

Exploratory Data Analysis (EDA) to uncover patterns and insights
